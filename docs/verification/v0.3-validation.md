# 0.3.0：受管账号、小工具与游戏验证

日期：2026-11-06。范围见 [ADR 0006](../adr/0006-managed-accounts-and-tools.md)。本记录区分本机源码验收、隔离 CI 和用户服务器；未连接或切换用户另一台 Windows 服务器。

## 数据与授权

- 本地 Windows、Node 22.14.0、PostgreSQL 18 隔离测试库：`npm run check` 的规范、ESLint、类型检查通过；81 项测试中 73 通过、0 失败、8 跳过（4 个 Linux 脚本用例、2 个外网采集用例、2 个平台权限用例）。跳过不计为通过。
- [账号集成](../../tests/auth.integration.test.ts) 使用真实 Better Auth、数据库运行角色与 Cookie。验证主账号 MFA、成员无验证码登录、禁用/改密/撤销、未知用户错误、限速、脱敏登录记录及审计不可被应用账号修改或删除。
- [真实成员 HTTP 检查](../../tests/helpers/member-data-http-checks.ts) 验证两成员与主账号跨资讯详情/修改、云盘列表/容量/分片/下载/HEAD/Caddy授权、导出列表/下载、游戏 scope 与版本的隔离。
- [数据隔离](../../tests/account-data.integration.test.ts) 使用受限 app/worker 角色验证相同来源、实体与外部 ID 可在账号间独立存在；复合外键拒绝跨账号关联，缺少账号上下文拒绝写入并不返回资料；30 个并发池请求不串账号。
- 采集更新保留个人备注、来源进度分别持久化，导出只包含本人资讯、关联、来源、文件元数据与游戏快照。停用成员停止新任务，但过期导出与回收站仍按保留期清理。
- 游戏保存使用原始字节快照和版本比较，并发同版本仅一个保存成功；错误 scope、过期版本、路径越界、类型不符、重复路径与超限请求被拒绝。
- 真实 Caddy 验证游戏保存接口允许 2 MiB 合成请求，超过 32 MiB 拒绝，非指定方法和其他业务接口仍维持小请求限制。

## 迁移、构建与恢复

- [升级测试](../../tests/account-migration.integration.test.ts) 从旧迁移建立实例，保留原主账号 ID、密码散列、MFA、会话与资讯，再应用新迁移；重复运行迁移不重复归属或修改已有凭据。新装通过同一迁移流程。
- 上游原始 1,892 个文件由 SHA-256 清单验证，本地改动路径明确记录；第三方既有格式保持原字节，本站新增代码继续执行正常检查。运行时资源不放入公开静态目录。
- 游戏 Web 专用构建已在本机 JDK 25 成功执行，JavaScript 语法检查通过，产物包含对应源码归档。Java 只用于构建。最终生产构建、浏览器游戏流程及远程 CI 结果在完成后补充，不能据此视为上线门禁已全部通过。
- `npm audit --omit=dev`：0 项已知生产依赖漏洞；这是当次 npm 审计结果，不是整站安全认证。
- 配对备份新增成员、审计、账号配置和游戏存档计数。恢复校验保留原数据库/云盘逐片完整性，并检查成员密码、停用状态、独立资料及存档版本；完整容器/restic 执行以本次 CI 记录为准。

## 生产边界

用户服务器的域名、服务路径、账号 ACL、Tunnel、备份目标与现有本地登录定制未在本机替代配置。按 [Windows 更新手册](../windows-update.md) 合并本地提交、准备 JDK 17+ 和 tar、在隔离副本验证后再切换。

多账号迁移后不能运行假定全库仅一个账号的旧应用；回退必须停止入口与写入、保护升级后的新增数据，再恢复迁移前数据库、文件及身份配置配对快照和匹配旧产物。截图使用合成账号与测试内容。浏览器模拟手机不等同于实体手机测试，游戏完整通关及全部浏览器兼容性不由本轮基础流程验收替代。
