# 0.3.0：受管账号、小工具与游戏验证

日期：2026-11-06。范围见 [ADR 0006](../adr/0006-managed-accounts-and-tools.md)。本记录区分本机源码验收、隔离 CI 和用户服务器；未连接或切换用户另一台 Windows 服务器。

## 数据与授权

- 本地 Windows、Node 22.14.0、PostgreSQL 18 隔离测试库：`npm run check` 的规范、ESLint、类型检查通过；91 项测试中 83 通过、0 失败、8 跳过（4 个 Linux 脚本用例、2 个外网采集用例、2 个平台权限用例）。跳过不计为通过。
- [账号集成](../../tests/auth.integration.test.ts) 使用真实 Better Auth、数据库运行角色与 Cookie。验证主账号 MFA、成员无验证码登录、禁用/改密/撤销、未知用户错误、限速、脱敏登录记录及审计不可被应用账号修改或删除。
- [真实成员 HTTP 检查](../../tests/helpers/member-data-http-checks.ts) 验证两成员与主账号跨资讯详情/修改、云盘列表/容量/分片/下载/HEAD/Caddy授权、导出列表/下载、游戏 scope 与版本的隔离。
- [数据隔离](../../tests/account-data.integration.test.ts) 使用受限 app/worker 角色验证相同来源、实体与外部 ID 可在账号间独立存在；复合外键拒绝跨账号关联，缺少账号上下文拒绝写入并不返回资料；30 个并发池请求不串账号。
- 采集更新保留个人备注、来源进度分别持久化，导出只包含本人资讯、关联、来源、文件元数据与游戏快照。停用成员停止新任务，但过期导出与回收站仍按保留期清理。
- 游戏保存使用原始字节快照和版本比较，并发同版本仅一个保存成功；错误 scope、过期版本、路径越界、类型不符、重复路径与超限请求被拒绝。
- [存档规范化回归](../../tests/game-bridge.test.ts) 验证文件顺序、偏好键顺序与时间戳不导致空写，真实内容变化仍被识别；新增两例在旧实现上失败、修正后通过。
- [游戏生命周期回归](../../tests/game-lifecycle.test.ts) 执行实际桥接脚本，8 项覆盖冲突后身份检查、迟到网络/保存/就绪事件、初始异常响应和父子状态握手；HTTP 401/403 的空或数组响应仍停止旧身份。旧实现的相应负例确实失败。
- 真实 Caddy 验证游戏保存接口允许 2 MiB 合成请求，超过 32 MiB 拒绝，非指定方法和其他业务接口仍维持小请求限制。

- 桌面实际创建战士，重新启动浏览器后继续同一存档，完成移动和战斗；网络断开显示未同步，可下载本次进度，恢复网络后同步。手机模拟 390×844 继续同一角色；修正后在移动中立即同步并旋转到 844×390、反向旋转，以及断网提示条出现/收起导致画布高度变化，均能完成回合并同步。
- 本机独立生产进程验证匿名及失效会话不能访问游戏入口、脚本和源码包；有效成员无需 MFA 登录，Cookie 使用 HttpOnly/Secure。游戏入口允许本站 iframe，普通登录页保持拒绝被嵌入。
- 游戏脚本及源码归档通过 HTTP 完整下载并与构建清单 SHA-256 一致；仅返回成功状态不计为完整传输。该测试进程已停止，不影响现有开发预览。
- [账号与工具页验收](tools-ui-validation.md) 覆盖管理、登录记录、成员登录、错误保留输入、键盘焦点和 320–1920 像素布局。新增正文最大宽度 1440px。
- [axe 原始结果](tools-axe-results.json)：13 个状态均为 0 项 violation；两个手机创建成员状态的同一说明文字保留 1 项对比度 incomplete，人工确认无遮挡，实际前景/背景对比度为 7.00:1。自动结果不替代屏幕阅读器或实体手机。
- [游戏交互验收](game-ui-validation.md) 单独记录真实游戏、旋转、并行冲突、登录失效与加载失败。两标签页仅进入菜单不会空写；真实冲突后暂停旧页并可下载含原生文件的备份。清除登录后，正常和冲突页都移除 iframe，并清理本次运行的 IndexedDB 与偏好。

## 生产边界

用户服务器的域名、服务路径、账号 ACL、Tunnel、备份目标与现有本地登录定制未在本机替代配置。按 [Windows 更新手册](../windows-update.md) 合并本地提交、准备 JDK 17+ 和 tar、在隔离副本验证后再切换。

多账号迁移后不能运行假定全库仅一个账号的旧应用；回退必须停止入口与写入、保护升级后的新增数据，再恢复迁移前数据库、文件及身份配置配对快照和匹配旧产物。截图使用合成账号与测试内容。浏览器模拟手机不等同于实体手机测试，游戏完整通关及全部浏览器兼容性不由本轮基础流程验收替代。
