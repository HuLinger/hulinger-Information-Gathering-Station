390 触屏模拟的文档宽度为 390；320 桌面模拟有原生滚动条，内容宽度为 305，不超过视口。手机文件操作按钮与刷新按钮实际高度至少 44 px，刷新按钮宽度为 44 px。截图检查包含首屏与滚动后的操作区，未把只检查文档宽度当作控件可达的证明。

等效缩放使用独立 Playwright 上下文的 720 × 450 CSS 视口与 `deviceScaleFactor: 2`，截图按 CSS 像素保存；这是页面重排与像素密度的等效验证，没有操作浏览器缩放菜单，也不代表“仅放大文字 200%”已验收。该视口内容宽度为 705（另有原生滚动条），1920 视口内容宽度为 1920，均无横向溢出。两种布局实际完成搜索、打开重命名与 Escape 归还焦点，独立验证浏览器已关闭；未操作此前的原生保存对话框。

本轮发现并修正：

- 手机搜索输入框内部的 44 px 最小高度与外层内边距叠加，造成 62 px 搜索框。限定云盘内部输入高度后，搜索框与按钮均为 44 px。
- 刷新按钮被 flex 压缩到约 34 px；现在固定为 44 px 触控范围。
- 普通下载链接继承了 Ant Design 默认蓝色，白底对比度只有 4.1:1；改为既有 `primary` / `primaryHover` 令牌。
- 品牌按钮的可访问名称缺少可见副标题；现在包含完整可见名称，并补上文本分隔。云盘容量使用带名称的 `group`。
- 组件派生的主按钮悬停颜色、成功标签背景没有达到本项目要求。`Providers` 映射已有的 `primaryHover` / `primaryActive`，并将 Tag 成功、错误、警告背景映射到已有 `surface`；没有增加另一套颜色或组件。实际完成态标签从 2.7:1 恢复为项目已验证的成功文字对白底组合。
- 等效 200% 页面缩放时，键盘 Tab 到文件动作，浏览器原先把焦点停在 y=393–437，而固定底栏从 y=385 开始，完全遮住焦点。现在仅在小于 768 px 且存在移动底栏的页面，给 `html:has(.mobile-bottom-nav)` 设置 `scroll-padding-top: calc(64px + 16px)` 与 `scroll-padding-bottom: calc(64px + 16px + env(safe-area-inset-bottom))`，为固定导航和焦点留出空间。

手机尺寸和搜索修正后的截图见上表。最后一轮主题映射以浏览器实际颜色、axe 复扫，以及新增的宽屏和等效缩放截图验证；此前阶段截图不是最终映射后的逐像素基线。

## 键盘与可访问性

实际键盘路径：跳到主要内容 → Enter → Tab 依次到上传、并行连接、文件页签、文件名搜索、搜索提交、刷新、下载、并行下载、重命名、删除。重命名支持 Enter 保存、Escape 取消，关闭后归还触发按钮；错误与未保存保护在真实表单中验证。

新增的等效缩放回归从搜索框出发，通过 Tab 依次到清除、搜索提交、刷新、关闭筛选、下载、并行下载、重命名、删除。八次焦点位置均在固定顶栏与底栏之间；修正后文件动作位于 y=326–370，底栏仍从 y=385 开始。重命名弹窗为 520 × 214，完整位于 720 × 450 视口内，关闭后焦点返回原按钮。1920 视口的弹窗为 520 × 206，也完整可见。新增验证没有页面脚本错误。

axe-core 4.14.0 扫描 WCAG 2 A/AA、2.1 A/AA、2.2 AA 标签：

- 最终桌面 1440 × 900，包含完成任务标签与上传按钮悬停：0 项 violation、32 项规则通过。
- 390 × 844 触屏布局：0 项 violation、31 项规则通过。此扫描包含搜索尺寸与链接颜色修正；最后集中主题映射另在桌面完成复扫。
- 两处均剩 1 项 `color-contrast` 自动未能判断：Ant Design Select 的文本与内部输入元素重叠，工具不能推断其背景。已人工查看文字、边框与焦点可辨认；此人工复核不等同于全套读屏或 WCAG 认证。
- 本轮操作没有观察到未处理的浏览器页面脚本错误。

代码校验：受影响的 `Providers.tsx`、`HubApp.tsx`、`DrivePanel.tsx` 的 ESLint 与 `tsc --noEmit` 通过。2026-11-05 再次执行 `npx tsx --test tests/drive-transfer.test.ts`：15 通过、0 失败、0 跳过，覆盖分片校验、并发界限、取消/暂停、乱序 Range 写入、续传、错误响应和磁盘写入失败。全仓库与生产构建结果统一见 [版本验证](v0.2-validation.md)。

## 验证边界

原生 File System Access 保存窗口未完成：Windows 自动化工具无法足够确认当前浏览器 URL，安全检查拒绝继续，因此停止该路径。未将模拟写入或模块测试称为真实保存成功，也未改变系统或浏览器安全设置。

本轮不宣称完成实体手机软键盘、NVDA/VoiceOver、仅放大文字的 200% 缩放、全部浏览器或目标服务器公网线路验证。永久删除的服务端行为另有集成测试，本轮浏览器只完成可恢复删除与恢复。实际部署仍需按 [上线门禁](../production-readiness.md) 和 [Windows 更新流程](../windows-update.md) 复验真实入口、文件保存、服务账号权限、备份与恢复。
