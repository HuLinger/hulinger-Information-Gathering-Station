## 数据与权限

- PostgreSQL/磁盘集成验证乱序并发、重复分片、重新创建存储实例后续传、截断/过长/校验失败/流中断、空文件、容量竞争、完成与取消竞争、回收站恢复、过期清理及孤儿对象。
- 真实身份库和隔离数据库验证匿名拒绝、非拥有者拒绝、MFA 前后权限、撤销会话，以及云盘读写 Origin 校验。
- Range/If-Range、HEAD、416、私有下载头和字节完整性经过应用路径与真实 Caddy 夹具验证；Caddy 丢弃客户端伪造文件定位头。CI 另执行真实登录/MFA、并行上传、容器/Caddy 与应用双路径下载和撤销会话校验，结果见下文远程检查入口。
- 恢复校验器实测接受完整配对文件，并拒绝缺失分片、错误大小和内容损坏。CI 另执行完整 restic 加密备份、配对恢复、运行角色与重启验证；恢复配置取自实际备份快照。
- NTFS 预分配实测回归：64 MiB 的暂存文件已消耗实际磁盘空间时，不再次扣除同一空间；稀疏文件仍预留未来写入空间。就绪检查使用真实读写/删除探针，避免 Windows `fs.access` 未检查 ACL 而误报可用；成功结果缓存 60 秒。
- 迁移 `004-drive.sql` 只新增云盘表和索引，不改既有身份与资讯结构；运行角色新增对应表权限。回退旧应用前保留新文件和表，数据库恢复必须与文件恢复来自同一备份点。

## 下载路由与取消回归

实际 HTTP 验证发现 Next.js 16.4.5 App Router 丢失下载 `Content-Length`，远程 CI 的 HEAD 断言也复现了该问题。保留同一 URL 与共享拥有者/MFA 授权，改用原生 Pages API HTTP 响应后，本地登录及 TOTP 验证后的 HEAD/GET 均返回 `100663296` 字节长度；96 MiB GET 全量 SHA-256 为 `896f545d8b03886d92d205934fc9c010da02f324d15bbfb7fdfc150161c9aff7`，与合成原文件一致。

11 月 5 日 07:53（Asia/Shanghai）另启动本次 `npm run build` 生成的 standalone 生产运行产物，在独立回环端口重复真实合成账号登录/MFA与 96 MiB HEAD/GET，长度、私有头和 SHA-256 同样一致，日志无重复监听或未捕获错误。该验证使用隔离测试数据库与本机文件；入口为回环 HTTP，尚不覆盖公网 TLS/Tunnel。

文件流另覆盖取消前后句柄关闭，以及慢消费者背压取消。Windows Node 22.14 的旧 adapter 在最新一次对照中 40 轮出现 33 次未捕获异常，当前实现 0 次；Node 24.22.2 的当前实现同样 40 轮无异常、无开放句柄。竞态次数随调度与 Node 版本变化，旧 adapter 在 Node 24 对照中未出现异常。详见 [下载取消验证](drive-download-cancellation.md)。

## 页面与交互

96 MiB 合成文件在真实浏览器完成上传、保存首片后暂停、刷新、重新选择原文件续传及普通下载；下载 SHA-256 一致。重命名、键盘焦点归还、回收站恢复、空搜索与断网重试均有操作记录，1440/768/390/320 视口保留截图。最终桌面 axe 0 项 violation、32 项规则通过；手机扫描 0 项 violation、31 项规则通过，Select 的一项自动对比度未决另作人工复核。

补充检查 1920×1080 与 720×450 CSS 视口、DPR 2 的等效 200% 页面缩放，搜索和重命名可达。缩放检查发现固定底栏遮住键盘焦点，增加移动滚动边距后，8 步 Tab 路径的焦点均在可视区内；该方法不等同于浏览器单独放大文字设置。

原生并行下载已进入选择保存位置，但系统保存对话框因自动审批无法确认浏览器 URL 而停止，未完成真实写盘验收；15 项传输模块测试不能替代该项。截图、状态、视口和其他验证边界见 [云盘页面验收](drive-ui-validation.md)。

## 大文件性能

512 MiB、32 个 16 MiB 分片、4 路并发的本机 HTTP 基准完成上传及双路径下载，全部 SHA-256 匹配。11 月 5 日下载取消修复后复测：上传 254.84 MiB/s、应用存储 Range 下载 432.02 MiB/s、直接文件流控制组 506.25 MiB/s。客户端与服务端同一个 Node 进程，本次峰值 RSS 330.00 MiB；该数据不是服务端单独内存。记录保留了 11 月 4 日的初测值，两次系统负载未受控，不据此宣称性能提升比例。

完整环境、命令和限制见 [基准记录](drive-benchmark.md)。它未经过 Next.js、Caddy、TLS、Cloudflare Tunnel 或公网，不能推导用户最大网速；部署后须沿实际线路验证，按瓶颈调整并发。
