# 更新历史

### 2026-11-06

#### 新增

- 0.4.0 增加“格式转换”小工具，统一中文选择文件、目标格式与可用引擎，接入 ConvertX、Transmute、Stirling-PDF 和 NCM 音乐转换。
- 已上传文件可复用，切换合适引擎无需重传；后台完成后下载结果，刷新页面可继续查看任务。
- 转换源文件和结果按账号隔离，默认保留 24 小时；可取消排队、重试失败任务或主动清理。
- 提供 Docker / WSL2 本地引擎安装与初始化流程，现有 Windows 网站和服务配置继续沿用。
- 0.3.0 增加“小工具”卡片页，首个工具为破碎的像素地牢 Web 版，提供独立游戏页面、电脑与手机布局，以及可继续开发的对应源码和构建说明。
- admin 主账号可创建、修改显示名、停用或启用成员，重置成员密码和撤销登录；成员使用用户名、密码直接登录，无需验证码，主账号继续使用双重验证。
- 主账号可查看成功和失败登录记录，记录中的网络地址经过脱敏，默认保留 30 天。
- 每个账号分别管理资讯、备注、关注、来源、云盘、导出和游戏存档；新账号初始为空，已有资料归原主账号。
- 游戏进度同步到当前账号，重新进入可继续；不同设备保存冲突时提示处理，网络失败不会显示已同步。
- 游戏支持移动中横竖屏切换；加载较久时显示等待与重新载入入口，设置项顺序变化不会制造无意义的存档更新。

#### 修复

- 0.3.1 修复地牢同层探索时，新显示的房间地形覆盖旧房间、遮住楼梯的画面错误；保留现有角色与存档，更新后重新载入游戏即可使用修复。

0.3.0 的多账号迁移需要先备份数据库与云盘，再在隔离副本验证。迁移后不能只切回旧版应用；回退须关闭入口并恢复对应备份。Windows 构建新增 JDK 17+ 和 tar 要求，运行网站无需 Java 服务。本次不操作用户另一台服务器，实际切换按 [Windows 更新手册](../windows-update.md) 完成。

0.4.0 需要另行启用本机转换引擎，未启用时页面会明确提示。NCM 提取原始 MP3 / FLAC，不承诺全部变成 MP3；PDF 转多页图片提供 ZIP。文件上限同时受网站、引擎和入口代理约束。安装与限制见 [转换工具部署](../../integrations/conversion/README.md)，此版本尚未部署到用户服务器。

### 2026-11-05

#### 新增

- 0.2.0 加入私有云盘，支持大文件分片上传、暂停和断点续传、进度与速度显示、文件搜索、重命名、回收站和恢复。
- 支持浏览器普通下载和兼容浏览器的并行校验下载；并发可调，文件按分片流式传输，避免整文件进入内存。
- 提供 Windows 候选更新工具：在独立目录合并上游并保留服务器本地提交，完成安装、检查与构建；冲突时保留候选目录，现有服务继续运行。
- Linux 升级保留本地配置与数据卷，升级前备份并记录旧版本；完整备份包含数据库和云盘文件，并可逐片校验恢复内容。

0.2.0 为可自行验证部署的小版本更新。用户现有服务器是 Windows 原生服务，带有本地登录定制和 Cloudflare Tunnel；本仓库未连接该服务器，也未替换其服务或配置。升级在服务器按 Windows 更新手册执行并验收。实际传输速度取决于客户端、磁盘、服务器出口和代理线路，本地测试不能代表公网满速。

### 2026-11-04

#### 新增

- 建立单人私有的 AI 情报与资料工作空间，登录后使用，支持双重验证和恢复码。
- 自动收集已启用的官方来源、发现 GitHub AI 项目、跟踪 Release，并保留可追溯的 Star 观测窗口。来源停用、配额耗尽、失败和信息不足均明确显示。
- 通过搜索、标签、私人备注、收藏、稍后读和归档整理资料；误删内容在期限内可从回收站恢复。
- 手动补充链接、修正字段、查看来源变化和修订记录，支持合并、拆分及撤销合并。自动同步不会覆盖人工修正。
- 支持后台生成包含内容、来源、实体关系和个人整理的 JSON 导出；任务可离开页面后再查看和下载。
- 提供适配电脑与手机的 Ant Design 界面，采用已确认的浅色侧栏与内容布局。
- 提供公开代码仓库 `hulinger-Information-Gathering-Station` 及 Docker Compose 安装说明，覆盖首次初始化、升级、加密备份和隔离恢复；部署后的资料仍由个人登录和双重验证保护。

#### 修复

- 异常数据响应会显示明确提示并支持重试，避免资料页面变为空白。
- 备注搜索保持模型与项目关联；刷新保留当前搜索，关闭详情或编辑窗口后恢复键盘焦点。

首版提供公开源码和自托管交付，实际生产环境按部署文档配置并验收。
