# 0.4.0 格式转换体验

依据 [ADR 0007](../adr/0007-private-format-conversion.md)。入口位于“小工具”，仍采用 Ant Design 与现有主题。所有操作要求有效本站会话，业务文件归当前账号。

## 操作闭环

1. 选择本地文件，或选择本人仍在保留期的已上传源文件。
2. 根据文件扩展名与实际可用引擎，选择目标格式。默认自动推荐，也可手动切换；只有支持当前目标的引擎可选。引擎健康或能力获取失败明确显示，允许刷新。
3. 首次上传显示实际字节进度；转换显示排队、处理阶段与终态，不伪造转换百分比。提交防重复；服务端限制每账号最多 5 个待处理任务。
4. 关闭页面后 worker 继续处理。重新进入从数据库恢复最近任务；上传尚未完成时不承诺断点续传。
5. 完成后显示实际结果名、大小及下载入口。结果只在已验证的文件落盘后发布。源文件可用于换格式或换引擎重试，不要求重新上传。
6. 排队任务可取消；运行任务等待完成。删除终态任务清理其结果；删除源文件明确确认将同时删除关联终态任务与结果。有排队或运行任务时拒绝删源。

首次上传文件默认最多 512 MiB；账号转换临时配额默认 5 GiB，最多 30 份源文件。单次结果默认累计最多 1 GiB / 100 个文件。输入、结果限制与保留空间由服务器配置；引擎、代理和实际展开大小也会限制处理，不将上限宣传为成功率。

## 格式与文案

所有按钮、状态、表单和可预期错误使用简体中文；产品名称与格式缩写保留原文。文件名保留中文，下载使用附件，不执行或在线嵌入输出。

- ConvertX：根据固定版本转换映射展示本站允许的实际文件格式，不接入 URL / 协议类输入。
- Transmute：读取能力，上传后再次核对文件自身兼容的目标格式。
- Stirling-PDF：只用核心 API，PDF 转文本/办公文档/图片及图片/办公文档转 PDF；多页图片返回 ZIP，选择文案明确标注。
- ncmdump-net：提取用户提供 NCM 中的原始 MP3 或 FLAC，选择项标记“原始音频（MP3 / FLAC）”，不把提取说成固定 MP3 转码。关闭外部封面请求。

本站选择范围小于上游全部能力；不宣称已经逐一验证每个格式组合。对于损坏、加密、不支持或耗尽预算的文件，保留源文件并给出中文失败和重试入口。

## 双端与状态验收

桌面、平板和手机使用同一工作台，表单与结果卡片按宽度重排；上传、选择目标、切换引擎、查看任务、下载、取消和清理均可达。长中文文件名折行，不挤出主要操作。

验收覆盖 1440×900、768×1024、390×844、320 CSS px 和 200% 文字缩放，键盘焦点、表单标签、确认弹窗与自动无障碍扫描。状态包括初次加载、无文件、无任务、引擎未启用、引擎断开、上传失败、任务失败、完成、文件过期和会话失效；失败保留仍有效的选择和源文件。

## 生命周期

上传完成后保留 24 小时；创建转换任务与成功完成会延长该源文件的保留期。结果完成后保留 24 小时，运行中断明确标为失败，需要用户重试；不会自动重复执行未知终态的上游任务。后台清理包含停用账号，停用账号不启动新转换。

本站临时目录不加入长期云盘备份。数据库恢复后结果文件缺失时返回“已到期或已被清理”，不伪造下载。引擎使用独立临时空间和清理策略，重建引擎不删除已由本站保存的结果。
