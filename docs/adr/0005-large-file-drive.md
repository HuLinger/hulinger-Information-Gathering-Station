# ADR 0005：大文件云盘与兼容升级

- 日期：2026-11-04
- 状态：采用，进入实现与验证。
- 需求依据：用户要求以小版本加入大文件云盘，尽量利用当前网络带宽，并方便更新已有服务器部署。
- 工程版本：从 0.1.0 增加到 0.2.0；仍按目标环境上线门禁验收，不把本地传输测试当作公网速度保证。

## 范围与架构

新增拥有者登录及 MFA 保护的云盘：文件列表与搜索、上传任务、暂停/续传、下载、重命名、回收站与恢复。沿用单人边界，不增加匿名分享、在线执行、解压、网页预览或第三方转存。

采用 PostgreSQL 保存元数据和分片完成记录，独立持久文件卷保存内容。Next.js 流式上传，按固定偏移写同一个对象；默认每片 16 MiB、4 路并发，可在界面调整至服务器允许的 1–8 路。每个请求独立文件句柄、处理短写、校验长度和 SHA-256、持久化后标记完成；不同片并行，同片与完成/删除操作协调。不把完整文件读入内存，不在完成阶段复制合并整个文件。

对象以服务端 UUID 命名，原文件名只作元数据。已完成对象不可变。支持经过鉴权的 GET/HEAD、Range/If-Range 与流式响应；默认 Caddy 可直接从只读文件卷发送，保留 Node 下载路径以兼容其他反向代理。下载强制 attachment、octet-stream、nosniff、private/no-store，禁止目录浏览和客户端自带的内部文件定位头。

浏览器上传以 Blob 分片和有界并发执行，校验续传文件与已保存分片一致。普通下载交给浏览器下载管理器；支持文件系统写入接口的浏览器提供并行下载与当前页面暂停/继续，直接按偏移写磁盘，不回退到整文件 Blob。浏览器关闭后的下载续传能力以浏览器原生下载管理器为准，不宣称所有浏览器均支持相同能力。

## 容量、权限与一致性

文件上限和空间预留可配置；创建上传前检查磁盘余量与其他上传的剩余预留，避免并发重复许诺容量。慢上传使用独立有界连接池、空闲和总时长限制，保留业务接口可用性。文件内容与服务端路径不进入日志；路径只由校验后的 UUID 生成，拒绝符号链接及越界。

部分上传默认保留 7 天，回收站默认 30 天，由 worker 清理；清理与上传/完成互斥。不可恢复清理须明确确认，失败保留可重试状态。数据库和文件系统不共享事务，必须有恢复状态与孤儿文件清理；下载只开放完成状态。

JSON 导出包含云盘元数据，不内嵌大型文件；完整备份必须包含数据库、文件卷与身份配置。备份期间协调物理清理，恢复后核对对象存在、大小和校验信息。

## 部署与更新

保留既有 Compose 项目名和数据库卷，新增云盘卷；外部磁盘通过本地覆盖配置挂载。升级把版本代码与服务器 `.env`、覆盖配置和数据分开，升级前检查定制、备份、迁移与健康，失败保留旧版本和回退材料。不得用 reset、clean、重新生成密钥或删除卷来强行更新。

用户补充现有服务器采用 Windows 原生 Node.js 24/PostgreSQL 18、独立服务账号、Cloudflare Tunnel 与 Caddy，并有两笔未上传的登录定制提交。该服务器不在当前开发环境。Windows 工具在服务器本地克隆现有 HEAD 至独立候选，普通合并指定上游并运行安装、检查、构建；冲突和检查失败保留候选，生产目录保持原样。实际激活沿用已有服务管理脚本，按 [Windows 更新流程](../windows-update.md) 验证 ACL、迁移、文件备份和服务切换。Linux 工具只处理干净且可快进的源码，遇到本地分叉明确停止。

## 备选方案

- S3/对象存储预签名直传适合跨机扩展，但增加服务、权限、域名和运维配置；当前单机自托管首选独立文件卷。
- 整文件经应用内存或数据库传输不适合本需求；分片独立存储再拼接会增加大文件完成时的磁盘占用与等待，故不采用。
- 单连接仍可能跑满线路；并行度可调而非越大越好。实际瓶颈可能在服务器出口、磁盘、CPU、代理、客户端和跨网线路。

## 验证要求

验证乱序、重传、并发同片、网络中断与服务重启续传、长度/校验错误、完成与清理竞争、空间预留、空文件、路径/符号链接、失效会话/跨站写入、Range/If-Range/416，以及旧版本升级、文件备份恢复和回滚。用大文件测内存与持续吞吐，记录环境并与同机直接传输比较；不承诺任何网络上固定速度或用户网速上限。
