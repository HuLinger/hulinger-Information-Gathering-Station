# ADR 0001：项目初始基线

- 日期：2026-11-04
- 状态：规范基线生效；具体应用技术选型待后续 ADR
- 背景：从空目录建立个人信息集合工具，目标为长期自用并部署上线。

## 决定

1. 在项目目录内建立独立 Git 仓库，避免使用父目录仓库。`main` 加短期工作分支，发布使用版本标签。
2. 采用用户明确选择的 Ant Design 作为唯一基础 UI 体系；设计令牌集中维护，无障碍目标 WCAG 2.2 AA，按实际页面验收。
3. 默认单人私有、关闭公开注册，优先完成收集/整理/查找/使用/导出闭环。该初始功能范围允许在明确需求后调整。
4. 在应用之前落地规范、基础检查、PR 模板和上线门禁。当前阶段不伪造业务构建或测试通过记录。
5. 应用与基础设施优先降低个人运维成本；框架、数据库、身份服务、托管平台、域名和费用在实现前综合决定。

## 取舍

短期分支避免个人项目维护多条长期分支。Ant Design 适配信息管理场景，但其默认组件不能自动保证所有组合页面符合无障碍和响应式要求。先设门禁可降低后续返工，代价是上线前必须补齐部署证据。

## 后续决策输入

明确主要信息类型、是否需要文件/RSS/抓取、预期数据量和设备，以及可用服务器、预算、域名与登录偏好。没有这些条件时可继续规范和本地原型工作，但不能将某一云服务或公开访问方式视为已获确认。

## 验证

规范与设计令牌由仓库检查维护；应用阶段补充真实类型/lint/测试/构建与 UI 验收；上线阶段按上线门禁提交证据。变更本决定时新增 ADR，并链接被替代决定。
